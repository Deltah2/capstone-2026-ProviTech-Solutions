## Objetivo

Configurar el repositorio oficial en GitHub siguiendo los estándares académicos del curso y establecer las bases organizativas del equipo Provitech Solutions, definiendo roles, normas de funcionamiento, confidencialidad y compromisos SMART para abordar el desafío del Hub Providencia.

## Actividades realizadas

1. Creación y configuración del repositorio del equipo en GitHub, estableciendo la estructura de directorios requerida (`bitacora/`, `imagenes/`, etc.).
2. Redacción del archivo `README.md` principal con la identidad del equipo, descripción del problema, valores y plan inicial de trabajo.
3. Elaboración y estructuración del documento formal "Contrato de Equipo y Compromiso SMART", estableciendo cláusulas de confidencialidad para el manejo de datos de la contraparte.
4. Resolución de problemas de versionado relacionados con la creación de subcarpetas y vinculación de imágenes mediante sintaxis Markdown.

## Decisiones y justificación

| Decisión | Evidencia o criterio | Consecuencia para el proyecto |
|---|---|---|
| Estandarización de nombres de archivos en minúsculas y sin espacios (ej. `foto-equipo.png`). | Requerimiento de buenas prácticas y prevención de errores de rutas web por sensibilidad a mayúsculas. | Evita problemas de despliegue, enlaces rotos en el Markdown y conflictos en el control de versiones. |
| Utilizar archivos `README.md` en blanco como "anclas" para crear subcarpetas vacías. | Git no rastrea ni permite subir directorios vacíos a la nube de manera nativa. | Permite mantener la estructura del repositorio intacta (`imagenes/S01`, `imagenes/S02`) desde la semana 1. |

## Errores, dificultades o riesgos

- **Qué no funcionó:** Inicialmente, las imágenes no se renderizaban en el `README.md` y las subcarpetas no se creaban correctamente en el repositorio.
- **Por qué creemos que ocurrió:** Desconocimiento inicial de que GitHub es estrictamente sensible a las mayúsculas/minúsculas en las rutas de los archivos (ej. `Imagenes` vs `imagenes`) y de que Git ignora las carpetas sin archivos en su interior.
- **Qué haremos para comprobarlo o corregirlo:** Modificamos la sintaxis de las rutas locales usando `./` para forzar la búsqueda en el directorio actual, renombramos los archivos conflictivos y validamos los cambios mediante la pestaña "Preview" antes de cada *commit*.

## Aprendizajes

El equipo asimiló cómo estructurar un repositorio académico de forma profesional, la importancia crítica de usar rutas relativas correctas para el contenido multimedia en Markdown, y la necesidad de establecer acuerdos de confidencialidad rigurosos antes de manipular procesos e información real de una institución pública como el Hub Providencia.
