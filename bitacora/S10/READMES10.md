## 2. Reestructuración del Repositorio en GitHub

A pesar de que toda la información del proyecto estaba presente, se nos solicitó aplicar una estructura más formal, limpia y dinámica para mejorar la experiencia del usuario o lector externo. 

**Acciones implementadas:**
*   **Formato Web (Landing Pages):** Se eliminó la dispersión de múltiples archivos pequeños por semana. Ahora cada semana (S02, S03, etc.) se consolida en un único archivo `.md` estructurado como una página web.
*   **Elementos Interactivos:** Se incorporaron etiquetas HTML (`<details>` y `<summary>`) para ocultar/desplegar las evidencias gráficas (fotos, mapas, PDFs transformados), manteniendo el texto principal limpio y ordenado.
*   **Convención de Nombres:** Estandarización de carpetas (ej. `imagenes/` en minúscula para asegurar el correcto ordenamiento alfabético en Git) y corrección de rutas relativas de las evidencias.
