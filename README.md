## Descripción

El Hub Providencia enfrenta dificultades en la gestión de reservas y control de uso de sus espacios (salas, cowork y especialmente laboratorios). Actualmente, este proceso exige una coordinación manual a través de múltiples canales, siendo el correo electrónico el método principal para los laboratorios. Esto vuelve el proceso engorroso, genera cuellos de botella para el equipo de administración y no deja un historial consolidado de uso. Nuestro proyecto busca resolver esto mediante una plataforma web que digitalice y automatice el ciclo completo de reservas, reduciendo el trabajo manual, incorporando una validación de uso de los espacios y generando un panel de datos para optimizar la gestión de la infraestructura.

## Desafío inicial

Sabemos que el Hub Providencia necesita automatizar sus reservas (especialmente los laboratorios) porque el sistema actual por correo es ineficiente y no genera datos históricos útiles. Aún no sabemos qué sistema de validación de acceso o confirmación de uso implementaremos (si un código QR, un pin, etc.), y necesitamos comprobar qué herramientas sin costo de licencias se adaptan mejor a la infraestructura del Hub.

## Objetivo SMART del equipo

Desarrollar un prototipo funcional de plataforma web para gestionar las reservas del Hub Providencia, priorizando el flujo de laboratorios, que reduzca los pasos manuales de reserva y genere un registro histórico básico, implementando herramientas sin costo de licencias de aquí a mediados de Noviembre de 2026.
